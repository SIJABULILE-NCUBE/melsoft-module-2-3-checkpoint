## About This Project

This project  combines what I learnt in Modules 2 and 3 through 12 practical challenges.

The challenges focus on variables,data types,type conversion,JavaScript operators,and user interaction.I also worked with real-life examples such as payroll calculations,banking transactions,shopping carts,form validation,and user permissions.

The aim of this project was to help me understand how JavaScript works and how to apply what I have learned when solving problems.

## What I Covered

- Declaring variables using `let` and `const`
- Working with different JavaScript data types
- Converting values from one data type to another
- Arithmetic,assignment,comparison,and logical operators
- Equality checks using `==` and `===`
- Operator precedence and ternary operators
- Short-circuit evaluation and optional chaining
- Bitwise operators for managing permissions
- Payroll,interest,and currency calculations
- Finding and correcting errors in JavaScript code
- Browser interaction using `alert()`,`prompt()`,and `confirm()`

### Main JavaScript File

Open the project in VS Code and run the following command in the terminal:

### Challenge 10

Open `challenge10.html` in a web browser.The interaction will start automatically when the page loads.You can also click the button to run it again.
